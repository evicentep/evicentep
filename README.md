## About me

I'm a fourth-year **Data Science & Engineering** student at the **University of Murcia**, on the joint degree programme with the **Technical University of Cartagena**.

I'm interested in how data moves from collection and storage to analysis and machine learning. My academic work includes cloud infrastructure with AWS, natural language processing of Reddit corpora, and a client–server application built around weather data from the AEMET API.

I'm currently bringing these projects together into a documented portfolio, with a focus on explaining the problem, the implementation and what I learned.

## Selected academic projects

### [AquaSenseCloud — AWS temperature data pipeline](https://github.com/evicentep/aquasensecloud)

A three-person academic project for processing temperature data, generating weekly and monthly summaries, sending alerts and serving results through a containerised API.

**Stack:** Python · AWS S3 · Lambda · SNS · ECS · Docker · Flask · CloudFormation  
**Focus:** Data pipelines · Cloud infrastructure · Team collaboration

### [Reddit NLP Analysis](https://github.com/evicentep/reddit-nlp-analysis)

A two-person notebook-based study of subreddit classification, semantic similarity, summarisation and prompted moderation, with recorded results and evaluation limitations documented.

**Stack:** Python · scikit-learn · fastText · Transformers · PyTorch  
**Focus:** Corpus analysis · Model comparison · Critical evaluation

### [AEMET Weather API](https://github.com/evicentep/aemet-weather-api)

A Flask REST API that retrieves and transforms AEMET forecasts and historical observations, with a Python client for visualising weather data.

**Stack:** Python · Flask · Requests · Matplotlib  
**Focus:** API integration · Data transformation · Client–server architecture
